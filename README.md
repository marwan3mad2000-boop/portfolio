# Marwan Emad — Portfolio

Personal portfolio site: dark theme with orange accents, animated intro, services, projects and a "Let's Work Together" contact section.

## Run it

It's a static site — no build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Works as-is on GitHub Pages, Netlify, Vercel or Firebase Hosting. For GitHub Pages: Settings → Pages → Deploy from branch → `main`.

## Before you share it — fill these in

Search the code for `TODO`:

1. **Email** — replace `you@example.com` with your real email (3 places in `index.html`).
2. **LinkedIn** — replace the `#` href on the LinkedIn button with your profile URL.
3. **CV** — add your CV as `cv.pdf` in this folder (the Download CV button points to it), or change the link.
4. **Projects** — the three project cards are placeholders. Swap in your real projects (title, description, link).

## Structure

```
index.html      all content and sections
style.css       theme, layout, animations
script.js       intro overlay, mouse glow, scroll reveals
assets/         photos and images
```

GitHub and WhatsApp buttons are already wired to your real accounts.
